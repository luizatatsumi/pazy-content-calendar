# Pazy Content Calendar

Calendário operacional de conteúdo da Pazy.

## V1
- Semana calculada por data
- Organograma recorrente
- Cobertura automática por “programado até”
- Check manual de um clique
- Instagram/LinkedIn identificados por ícone
- UX compacta e responsiva

## Rodar localmente
```bash
npm install
npm run dev
```

Branch de desenvolvimento: `dev`.
